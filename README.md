I created the project folder "DataFlowGame".
The structure of this folder looks like that:
DataFlowGame/
│
├── main.py
│
├── data/
│   └── orders.xlsx
│
└── save/

before starting the game youll need these libraries:
Pandas:
python -m pip install pandas

Openpyxl:
python -m pip install openpyxl

numpy:
python -m pip install numpy

matplotlib:
python -m pip install matplotlib

seaborn:
python -m pip install seaborn
